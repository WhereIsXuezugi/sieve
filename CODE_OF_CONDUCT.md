# Code of conduct

## The short version

Be civil. Assume the other person is arguing in good faith until they clearly
are not. Criticise the design, not the designer.

## What that means here

This project invites disagreement — the README contains a table of eleven tools
it declined to use, and every row is an opinion someone might reasonably
dispute. Technical argument is welcome and does not need softening. Contempt
does.

Specifically:

- Harassment, personal attacks, and sustained disruption are not acceptable.
- Demeaning comments about someone's identity, background or experience level
  are not acceptable.
- Publishing someone's private information is not acceptable.
- "I was only being honest" is not a defence for being unkind. Honesty and
  cruelty are unrelated.

Asking a beginner's question is always fine. So is saying you do not know
something.

## Enforcement

Report problems through GitHub's private reporting on this repository, or by
opening an issue if the matter is not sensitive. Maintainers may edit, hide or
delete contributions, and may block accounts, when this document is not
followed. Decisions will be explained where explaining them does not expose the
reporter.

Maintainers are held to this document too, and more so.
